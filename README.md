# 天际之城 · 城市建造

一个用 **Three.js** 制作的轻量城市建造游戏，玩法参考《城市：天际线》，但做了大幅简化：修路、划区、供电、建设施，看着城市从村庄长成摩天大楼林立的都会。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。打包发布用 `npm run build`，产物在 `dist/`。

## 玩法

1. **修路**：从地图左侧的高速入口开始拖动修建道路。只有连到高速的道路网才能让城市发展。
2. **划区**：在道路两旁框选住宅（R）、商业（C）、工业（I）区，开发商会自动建房。
3. **供电**：没有电，新建筑不会开工。可以选风力发电机（清洁）或火力发电厂（电多但有污染）。
4. **看需求**：左下角的 RCI 柱状条显示三类区域的需求，哪一类高就多划哪一类。
5. **升级**：公园、学校、医院、地标都会提高地价和幸福度，建筑因此升级为中、高密度，最高可长成摩天大楼。工业的升级靠教育。
6. **里程碑**：人口达到一定数量会解锁新建筑并获得奖金；左侧「城市目标」面板会一步步引导新手。

| 操作 | 按键 |
| --- | --- |
| 平移 | 右键拖动 / WASD，查看模式下也可以左键拖动 |
| 旋转 | 中键拖动 / Q、E |
| 缩放 | 滚轮 |
| 暂停 / 速度 | 空格 / 1、2、3 |
| 取消工具 | Esc / 右键单击 |
| 快捷工具 | R 修路，B 推土机 |

点击建筑可查看居民、幸福度、地价和升级条件；点击顶栏的资金可打开预算面板调整税率。右下角可以切换地价、污染、服务覆盖三种热力图。游戏每天自动存档到浏览器本地。

## 画面特性

- 全部模型都在代码中程序化生成，不依赖外部美术资源：9 类区域建筑共 40 多种变体，另有 12 种特殊建筑（摩天轮、电视塔、体育场、医院、学校、火电厂等）
- 建筑使用实例化渲染，几百栋建筑也只需要很少的绘制调用
- 有完整的昼夜循环：日出日落、星空、夜间窗户亮灯、路灯光晕、霓虹灯、航空障碍灯，夜里开启泛光效果
- 车辆在路网中行驶，会经高速公路进出城市；烟囱冒烟、冷却塔出蒸汽、风车转动、摩天轮旋转、喷泉喷水
- 河流与湖泊可以架桥跨越，地图外围有山地和森林

## 目录结构

```
src/
  core/      配置、工具函数、程序化建模与实例化批次
  models/    区域建筑、特殊建筑、道具（树、车、路灯）模型
  world/     渲染：环境与昼夜、地形、道路、覆盖层、粒子、车辆、城市视图
  game/      城市模拟、地图生成、输入、音效
  ui/        HUD 界面
```
